
# 🧾 Task 8 - Simple Sales Dashboard Design

## 📌 Objective:
Create a basic interactive dashboard that shows **sales performance** by product, region, and month using **Power BI**.

---

## 🛠 Tools Used:
- Power BI
- Microsoft Excel (for data preview and minor cleaning)
- Dataset: `Superstore_Sales.csv` (Columns: Order Date, Region, Category, Sales, Profit)

---

## 📈 Dashboard Features:
- **Line Chart**: Monthly sales trend (Order Date → Month-Year)
- **Bar Chart**: Sales performance by Region
- **Donut Chart**: Sales by Product Category
- **Slicer**: Region-wise filtering

---

## 📊 Key Insights:
1. The **West region** had the highest sales in Q3.
2. **Technology category** contributed the most to total sales.
3. A noticeable spike in sales occurred in **December**, likely due to year-end promotions.
